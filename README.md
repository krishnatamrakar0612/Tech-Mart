🛍️ Tech-Mart – Modern Fashion E-Commerce Website

Tech-Mart is a modern, responsive fashion e-commerce website built using HTML, CSS, and JavaScript.
It showcases stylish layouts, product sections, and a clean user experience designed for online fashion stores.

🌟 Features

🧥 Responsive Design – Fully optimized for mobile, tablet, and desktop devices

🛒 Product Showcase – Attractive product cards with images and hover effects

🔍 Search & Categories – Easy navigation for users to find what they need

💳 Checkout UI – Simple cart and checkout interface

🦶 Modern Footer – Includes company info, social icons, and contact links

🎨 Custom Styling – Elegant color palette and typography for a fashion-centric look

🖥️ Tech Stack
HTML5 – Structure
CSS3 – Styling & Layout
JavaScript (ES6) – Interactivity
(Optional) React.js if you later add dynamic components
